### Шаг 1: Установка MSYS2

MSYS2 — это современная среда, которая предоставляет доступ к огромному репозиторию пакетов, включая компиляторы GCC и отладчик GDB.

1.  **Скачайте установщик:** Перейдите на официальный сайт [msys2.org](https://www.msys2.org/) и скачайте последнюю версию установщика (файл `msys2-x86_64-...exe`). В качестве альтернативы можно использовать Winget в PowerShell: `winget install -i MSYS2.MSYS2`.
2.  **Запустите установку:** Откройте скачанный файл. В окне установки рекомендуется оставить путь по умолчанию — `C:\msys64`. Это короткий ASCII-путь без пробелов и символов, что избавит вас от многих потенциальных проблем в будущем.
3.  **Завершение:** После завершения установки автоматически откроется терминал **MSYS2 UCRT64**. Это именно то окружение, которое нам нужно.

### Шаг 2: Установка компилятора и отладчика

Теперь установим всё необходимое для компиляции и отладки. В открывшемся терминале **MSYS2 UCRT64** выполните одну команду, которая установит полный набор инструментов, включая GCC, G++ и GDB:

```bash
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
```

*   `--needed` — пропустит уже установленные пакеты.
*   `base-devel` — базовые инструменты разработки.
*   `mingw-w64-ucrt-x86_64-toolchain` — группа пакетов, которая включает в себя `gcc`, `g++`, `gdb` и другие необходимые утилиты.

Во время установки `pacman` может запросить подтверждение — просто нажмите `Enter` (по умолчанию выбрано `Y`).

### Шаг 3: Проверка установки

Не закрывая терминал, проверьте, что все инструменты на месте. Выполните по очереди эти команды:

```bash
gcc --version
g++ --version
gdb --version
```

Вы должны увидеть информацию о версии для каждого инструмента. Если все три команды отработали без ошибок, значит, установка прошла успешно.

### Шаг 4: Установка расширения C/C++ в VS Code

1.  Откройте **Visual Studio Code**.
2.  Перейдите в панель расширений (значок квадратов на боковой панели) или нажмите `Ctrl+Shift+X`.
3.  В строке поиска введите `C++`.
4.  Найдите расширение **C/C++** от Microsoft (его идентификатор — `ms-vscode.cpptools`) и нажмите **Install**.

### Шаг 5: Настройка проекта в VS Code

Теперь создадим простой проект и настроим его для сборки и отладки.

1.  **Создайте папку проекта**, например, `C:\Projects\HelloWorld`, и откройте её в VS Code (`Файл` -> `Открыть папку...`).
2.  **Создайте файл** `main.cpp` в этой папке и вставьте простой код:
    ```cpp
    #include <iostream>

    int main() {
        int a = 5;
        int b = 10;
        int sum = a + b;
        std::cout << "Sum is: " << sum << std::endl;
        return 0;
    }
    ```
3.  **Настройте сборку (`tasks.json`):**
    *   Нажмите `Ctrl+Shift+P`, чтобы открыть палитру команд.
    *   Введите `Tasks: Configure Default Build Task` и выберите `C/C++: g++.exe build active file`.
    *   VS Code создаст файл `tasks.json` в папке `.vscode`. Он будет настроен на компиляцию текущего файла. **Важно:** Убедитесь, что в аргументах компилятора есть флаг `-g`. Он добавляет отладочную информацию, без которой GDB не сможет показать вам значения переменных. Примерная конфигурация будет выглядеть так:
        ```json
        {
            "version": "2.0.0",
            "tasks": [
                {
                    "type": "cppbuild",
                    "label": "C/C++: g++.exe build active file",
                    "command": "C:\\msys64\\ucrt64\\bin\\g++.exe",
                    "args": [
                        "-fdiagnostics-color=always",
                        "-g",
                        "${file}",
                        "-o",
                        "${fileDirname}\\${fileBasenameNoExtension}.exe"
                    ],
                    // ... остальные поля
                }
            ]
        }
        ```
4.  **Настройте отладку (`launch.json`):**
    *   Нажмите `Ctrl+Shift+P` и выберите `Debug: Add Configuration` -> `C++ (GDB/LLDB)` -> `g++.exe build and debug active file`.
    *   VS Code создаст файл `launch.json`. Ключевой параметр, который нас интересует, — это `"miDebuggerPath"`. Он должен указывать на полный путь к `gdb.exe`:
        ```json
        {
            "version": "0.2.0",
            "configurations": [
                {
                    "name": "C/C++: g++.exe build and debug active file",
                    "type": "cppdbg",
                    "request": "launch",
                    "program": "${fileDirname}\\${fileBasenameNoExtension}.exe",
                    "args": [],
                    "stopAtEntry": false,
                    "cwd": "${fileDirname}",
                    "environment": [],
                    "externalConsole": false,
                    "MIMode": "gdb",
                    "miDebuggerPath": "C:\\msys64\\ucrt64\\bin\\gdb.exe",
                    "setupCommands": [
                        {
                            "description": "Enable pretty-printing for gdb",
                            "text": "-enable-pretty-printing",
                            "ignoreFailures": true
                        }
                    ],
                    "preLaunchTask": "C/C++: g++.exe build active file"
                }
            ]
        }
        ```
    *   **Обратите внимание:** В вашем файле путь к `gdb.exe` может быть другим (например, `C:\\msys64\\mingw64\\bin\\gdb.exe`), если вы использовали другое окружение MSYS2. Вы можете узнать точный путь, выполнив в терминале MSYS2 команду `which gdb`.

### Шаг 6: Запуск отладки

Поставьте точку останова (кликните слева от номера строки `int sum = a + b;` — появится красная точка) и нажмите `F5` или выберите `Run and Debug` в левой панели.

Программа скомпилируется, запустится и остановится на вашей точке останова. В левой панели вы сможете увидеть значения всех переменных. Поздравляю, ваша среда разработки полностью настроена!
